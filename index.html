FAQ

What is Zuvnelo?

Zuvnelo is an all-in-one media utility interface.

Why does every platform have a separate page?

Each platform can have its own interface and processing system, making the website easier to use.

Can social-media links be processed directly?

Social-platform processing requires a suitable backend or authorized API integration. The GitHub Pages frontend alone cannot perform that server-side processing.
